
# Bank Account Management System 🏦💼

This project is a simple bank account management system written in Ruby. It allows users to create and manage bank accounts with functionalities such as deposits, withdrawals, and balance checking. The system is designed to provide a basic understanding of object-oriented programming concepts in Ruby.

## Features ✨
- Create a new bank account with an account number, initial balance, and account holder's name.
- Deposit money into the account.
- Withdraw money from the account, with validation to prevent overdrafts.
- Check the current balance of the account.

## Usage 🛠️
1. **Create an Account**:
   - Initialize a new bank account with account number, balance, and account holder's name.
   
2. **Deposit Money**:
   - Use the `deposit` method to add money to the account.
   
3. **Withdraw Money**:
   - Use the `withdraw` method to take money out of the account, ensuring the withdrawal amount does not exceed the current balance.
   
4. **Check Balance**:
   - Use the `check_balance` method to display the current balance of the account.

## Requirements 📋
- Ruby
- Pry (for debugging)
